# Правила проекта «Арт-деко»
- Перед изменениями прочитай `PRODUCT.md`, `FLOW.md` и `TASKS.md`.
- Выполняй одну пользовательскую задачу за раз.
- До правок покажи короткий план и способ ручной проверки.
- Меняй только согласованный кусок; архитектуру и библиотеки — лишь с объяснением.
- Не помещай секреты и реальные данные клиентов в код, логи и публичные настройки.
- Не ослабляй доступ к данным и не удаляй рабочее поведение ради упрощения.
- Давай коммитам понятные названия, которые напоминают, что изменилось для пользователя.
- После правок запусти `npm run check` и покажи файлы, результат и ручной чек-лист.
- После изменений синхронизируй `AGENTS.md`, `CLAUDE.md` и связанные проектные документы.
- При противоречии остановись, назови его и запроси решение.

## Главная страница
- Информация о компании хранится в `project.company`, фотографии слайдера — в `project.recentWorks` (`src`, `alt`). Подписи поверх фотографий не показываются.
- Интервал слайдера главной — 4000 мс; сохраняй ручное управление, паузу, поддержку уменьшения движения и очистку таймера при смене страницы.
- На первом экране ссылки Instagram и Telegram показываются компактными значками под телефоном; полные кнопки остаются в подвале.

## Страница «О компании»
- Редактируемые тексты, портрет, последние работы и нижняя фотогалерея хранятся в `project.about`.
- Сохраняй порядок: знакомство с декоратором, последние работы, общая информация.


## Заказ и социальные сети
- Карточка заказа доступна по `#/request` и отправляет данные в `POST /api/applications`; локально API находится на `127.0.0.1:3000`, production API — на `https://api.artdeco-vl.ru`.
- Сохраняй два сценария: `catalog` требует позиции корзины, `custom` требует `wishes` и отправляет пустой `cart_items`.
- Не очищай форму и корзину при ошибке API. Корзину можно очистить только после ответа `{ success: true }`.
- Backend сверяет позиции с `src/project.js`, подключает PostgreSQL только через `DATABASE_URL` и вызывает MAX после успешного `INSERT`. Секреты не помещай во frontend и логи.
- Ссылки Instagram и Telegram редактируются в `project.socials`. Пустая ссылка остаётся неактивной; не подставляй вымышленные адреса.
