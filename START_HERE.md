# Начни здесь

Frontend работает на обычном JavaScript без сборщика. Для production-заявок в
проект добавлен отдельный Node.js API с PostgreSQL.

## 1. Проверь компьютер

```bash
npm run doctor
```

Если Node.js не найден, установи актуальную LTS-версию с официального сайта Node.js.

## 2. Запусти проект

```bash
npm ci
npm run dev
```

Для проверки формы создай `.env` по примеру `.env.example` и во втором терминале
запусти `npm run api:dev`. Открой `http://127.0.0.1:4173`.

## 3. Дай агенту первый промпт

```text
Прочитай START_HERE.md, AGENTS.md, PRODUCT.md и текущие файлы проекта.
Пока ничего не меняй.

Объясни простыми словами:
1. Что уже работает.
2. Где меняется название и текст.
3. Где хранятся локальные записи.
4. Как проверить проект.
5. Какой самый маленький шаг превратит starter в мой продукт.

Мой продукт: [одно предложение].
```

## 4. Сохрани рабочую точку

```bash
git init
git add .
git commit -m "Стартовый проект работает"
```

Команды можно выполнить через агента или GitHub Desktop.
